## Build sequence

```sh
pdflatex -interaction=nonstopmode imr_critique.tex   # pass 1: aux, toc, idx
pdflatex -interaction=nonstopmode imr_critique.tex   # pass 2: STABILIZE pagination
makeindex imr_critique.idx                           # -> imr_critique.ind
pdflatex -interaction=nonstopmode imr_critique.tex   # pass 3: typeset the index
pdflatex -interaction=nonstopmode imr_critique.tex   # pass 4: settle refs
```

**Why two passes before `makeindex` (round-9 Patch Set 9).** Running
`makeindex` after a single pass indexes page numbers from a run whose table of
contents had not yet stabilized pagination, and the resulting index references
are about two pages early. Two passes first, then `makeindex`, then two more,
reproduces the shipped `imr_critique.ind` byte-for-byte and the shipped PDF
pixel-for-pixel on all 51 pages. Alternatively, keep the shipped `.ind` and do
not regenerate it.

Four pdflatex passes are required: passes 1 and 2 emit the `.idx`; `makeindex`
produces the `.ind`; passes 3–4 resolve the generated index, contents, `\ref`/`\eqref`, and
hyperref anchors.

## Reproducibility criterion (semantic, not byte-identical)

An independent rebuild under a different TeX Live release compiles cleanly but
can regenerate a byte-different `.ind` and therefore a byte-different final
page. The reproducibility criterion for this package is **semantic and visual**:
same page count, same section and float numbering, same index entries, no new
warnings. Byte identity requires archiving the container image; if that matters,
pin the environment (Docker/Nix/Guix/Apptainer) rather than comparing hashes.

## arXiv submission

**Filename.** Upload the archive as exactly `arxiv-submission.tar.gz`. Browsers
often save a repeated download as `arxiv-submission.tar(5).gz`; arXiv's filename
rules do not accept parentheses, so rename before upload.


Upload `arxiv-submission.tar.gz`. Contents:

```
imr_critique.tex      main source

```

arXiv treats a top-level `anc/` directory as ancillary material and does not
attempt to compile it. No `00README.XXX` directives are needed; the default
pdflatex route compiles the source directly. Metadata fields — title, authors,
categories (cs.AI primary, cs.CL cross-list), comments, and the
1,879-character abstract — are in `arxiv_metadata_abstract.tex`.
